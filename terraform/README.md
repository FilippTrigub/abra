# Azure Terraform Deployment for Abra

This repo contains Terraform infrastructure-as-code for deploying the Abra platform on Azure.

Status: the Terraform layout is implemented and `terraform validate` passes for the production root module.

## Architecture

The infrastructure is split into three concerns:

1. **Bootstrap** — creates the Terraform remote state backend (storage account + container)
2. **Shared foundation** — Azure Container Registry, Blob Storage, Service Bus, Key Vault, PostgreSQL, Container Apps Environment, Log Analytics
3. **Application compute** — public HTTP control-plane router + per-user agent Container Apps

### Module Structure

```
terraform/
├── README.md
├── bootstrap/              # Phase 1: remote state backend
├── backend/                # Remote state configuration per environment
├── modules/
│   ├── foundation/         # Phase 2: shared platform resources
│   ├── router/             # Phase 3: HTTP control-plane
│   └── agent/              # Phase 4: per-user agents
└── environments/
    └── prod/               # Phase 5+: production deployment
```

## Prerequisites

- Terraform >= 1.6
- Azure CLI authenticated (`az login`)
- A subscription with permissions to create Azure resources

## Quick Start

```bash
cd terraform

# Step 1: Bootstrap the remote state backend (one-time)
cd bootstrap
terraform init
terraform plan -out=tfplan
terraform apply tfplan
cd ..

# Step 2: Deploy the production environment
cd environments/prod
terraform init
terraform plan -out=tfplan
terraform apply tfplan
```

## Runtime State Mapping

This infrastructure provisions Azure resources. The application code must still be adapted to consume them:

| Repo concept | Azure resource |
|---|---|
| `~/.openclaw/openclaw.json` | Key Vault secrets + env references |
| `~/.openclaw/workspace-abra/` | Per-user blob prefix |
| `skills/brand-manager/brand-assets/` | Blob container (`brand-assets`) |
| `input/staging/` | Blob container (`input/{user}`) |
| `output/` | Blob container (`output/{user}`) |
| `archive/` | Blob container (`archive/{user}`) |

See individual module READMEs for variable details.

## Provider Version Pinning

Providers are pinned in `environments/prod/providers.tf`. Never edit that file manually — it is generated by `terraform init`.
